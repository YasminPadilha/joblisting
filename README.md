# Job Listing App (React + Vite)

This is a simple job board app built with **React**, **Vite**, **Tailwind CSS**, and a mock backend using **JSON Server**. It allows users to view and filter job listings based on tags and categories.

## 🔧 Features

- React 19 + Vite setup
- Tailwind CSS for styling
- Dynamic filtering of job posts
- Mock API with JSON Server
- React Router for navigation
- Toast notifications for interactions

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YasminPadilha/joblisting.git
cd joblisting

### 2. Install dependencies
npm install

### 3. Start the development server
npm run dev

It will run the API on:
http://localhost:3000/
